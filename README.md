# Lumina - Contemporary Fine Dining Restaurant

A premium restaurant website showcasing contemporary fine dining experience in Lagos. Built with PHP, HTML, Tailwind CSS, and JavaScript, Lumina provides an elegant online presence for restaurant operations and customer engagement.

## 🌟 Features

- **Elegant Homepage** - Stunning hero section with smooth animations and modern design
- **Dynamic Menu Management** - Showcase culinary offerings with detailed descriptions
- **Online Reservations** - Easy-to-use booking system for table reservations
- **Photo Gallery** - Visual showcase of ambiance, dishes, and dining experience
- **About Section** - Restaurant story, values, and team information
- **Contact & Location** - Easy contact options including WhatsApp integration
- **Local SEO Optimization** - Built-in SEO meta tags for Lagos and fine dining search visibility
- **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- **Modern UI/UX** - Gold and dark theme with Playfair Display typography for luxury feel

## 🛠️ Tech Stack

- **Backend**: PHP
- **Frontend**: HTML5, Tailwind CSS
- **JavaScript**: Vanilla JS for interactivity
- **Styling**: Tailwind CSS with custom brand colors
- **Icons**: FontAwesome 6.4.0
- **Fonts**: Google Fonts (Playfair Display & Inter)

## 🚀 Getting Started

### Prerequisites
- PHP 7.4 or higher
- Web server (Apache, Nginx, or built-in PHP server)
- Modern web browser

### Installation

1. **Clone or download the project**
   ```bash
   cd Lumina_Fine
   ```

2. **Start a local server** (using PHP built-in server)
   ```bash
   php -S localhost:8000
   ```

3. **Open in browser**
   ```
   http://localhost:8000
   ```

### Alternative - Using Apache
- Place the project in your Apache `htdocs` folder
- Access via `http://localhost/Lumina_Fine`
